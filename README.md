# 📊 Olist E-Commerce Analytics Platform

An end-to-end E-Commerce Business Intelligence project built using Python, PostgreSQL, SQL, and Streamlit.

## 🚀 Project Overview

This project analyzes Brazilian Olist E-Commerce data to identify business performance, customer behavior, sales trends, delivery performance, payment patterns, and customer retention.

The platform automates data ingestion, transformation, validation, SQL analysis, and interactive dashboard reporting.

## 🏗️ Technology Stack

- Python – Data processing and automation
- PostgreSQL – Database management
- SQL – Business analytics
- Streamlit – Interactive dashboard
- Pandas & NumPy – Data transformation
- Plotly – Data visualization

## ⚙️ Project Architecture

Raw CSV Data → Data Ingestion → Data Cleaning → Data Validation → PostgreSQL → SQL Analytics → Streamlit Dashboard

## 📈 Business Analysis Modules

1. Sales and Revenue Analysis
2. Customer Analysis

4. RFM Segmentation

7. Seller Performance Analysis
8. Payment Analysis

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/indra1819/olist-ecommerce-analytics.git
cd olist-ecommerce-analytics
```

Create virtual environment:

```bash
python -m venv .venv
```

Activate environment:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure PostgreSQL credentials using `.env.example` as a reference.

Run dashboard:

```bash
streamlit run dashboard.py
```
